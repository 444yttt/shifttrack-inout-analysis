# 設定、遅刻、概要

## SettingsView

descriptor `0x100440448`、アクセサ `0x10018d1c8`。専用関数 `0x10018dc8c`（5164 バイト）。

確定。この関数は「メッセージの文章」「シフトの重なり」「IN/OUT について」「勤務先の移動にかかる時間」を読む。説明 `0x1004ff820` は、時間の重なりと、違う勤務先の間が移動時間より短いときの保存前確認である。`0x1004ffba0` は、カレンダーとリマインダー、端末内の保存、地図と所要時間、新しいバージョンの確認（App Store の公開情報）、Google マップのリンクからの勤務先の読み込み、を一つの文で読む。

バージョンの取得 `0x10001e4d0` は画面アクセサを呼ばない。`mainBundle` の `bundleIdentifier` を `https://itunes.apple.com/lookup?bundleId=` に付け、`URLSession.sharedSession` を使う。`0x10001e810` は `CFBundleShortVersionString` を読む。結果の「App Store を開く」はルートだけの `0x10017f2ec` が読む。「新しいバージョンがあります」は `0x100179048` が読む。この関数はルートとオンボーディングの両方を呼ぶ。

部分。`0x10018d200` は `SettingsView`、`AboutView`、`LateTemplateSheet` を呼び、`sheet` が 1、`sheet(item:)` が 1。`0x100194a98` は「設定アプリで許可する」「リマインダー」「位置情報の許可」を読む。`0x100190464` は「位置情報を許可する」「シフトの前に通知」を読む。どちらも専用関数の範囲の外。通知のクラスは `logic.md`。

確定。`requestAuthorizationWithOptions:completionHandler:` を呼ぶ `0x100191250` と `0x1001945ec` は、どちらも直前の `movz w2, #7` でオプションを渡す。呼び出し元は一つずつで、どちらも `SettingsView` のアクセサだけを参照する関数へ届く。7 はビット 1、2、4 の和である。`requestFullAccessToEventsWithCompletion:` の `0x1000f44d4` も、同じように設定だけへ届く。通知を何分前に作るかは、この 2 つの呼び出しには無い。

確定。`chevron.right` は `0x10018fa54`、`minus` は `0x100193588`、`plus` は `0x100193ebc`、`arrow.up.right` は `0x100199f98`。いずれも `Image(systemName:)` で、呼び出し元を辿ると設定のアクセサだけに届く。専用関数 `0x10018dc8c` の中ではない。画面の中の位置は未確定。

確定。このアクセサだけを参照する関数が `EdgeInsets.init(_all:)` に 8、12、20、24 を渡す。24 は `0x10018dc14`。専用関数 `0x10018dc8c` の直前であり、その関数の中ではない。画面の中の位置は未確定。

未確定。積み順、角丸、フォント。

## AboutView

descriptor `0x10043d9ac`、アクセサ `0x100009a10`。専用関数 `0x100004c68`。

部分。設定側の `0x10018d200` がこのアクセサを呼ぶ。`0x10017c7f0` は「App Store を開く」「この日のシフトを編集」を読む。専用関数ではない。

確定。`chevron.right` は `0x100005bec`、`arrow.up.right` は `0x100006a18`。どちらも `Image(systemName:)` で、呼び出し元を辿ると `AboutView` のアクセサだけに届く。

未確定。積み順、余白、フォント、文言の所属。

## LateMessageView

descriptor `0x10043f300`、アクセサ `0x1000cede8`。専用関数 `0x1000c551c`（4456 バイト）。

確定。この関数は `onChange` を 6、`toolbar` を 1 持つ。`0x1000c5114` はこのアクセサだけを呼び、`NavigationStack` を作る。

部分。`0x1000c4b00` は「寝坊してしまって」「寝坊してしまい」「体調が優れないため」「体調が悪くて」「電車の遅延で」「分ほど遅れます」を読む。`0x1000c6684` は専用関数の終端にあり、「電車の遅延のため」「① 遅れる理由」「② 遅れる時間」「③ 言葉づかい」「文章はここで直せます。①〜③の答えを変えると作り直します。」を読む。`0x1000d2a5c` は「分くらい遅れます」「ごろになります」を読む。ルートと一覧と勤務先のハブが、他の画面と一緒にこのアクセサを呼ぶ。

部分。場所の許可 `requestWhenInUseAuthorization` を呼ぶ `0x1000d853c` は、場所の選択だけの `0x100238b4c` から届く。同じ関数は `0x100218c0c` からも届き、その先 `0x1000cbc74` は遅刻のアクセサだけを参照する。どちらの画面のボタンが許可を求めるかは、この共有だけでは決まらない。

未確定。積み順、余白、フォント、記号、定型文の選択式。
