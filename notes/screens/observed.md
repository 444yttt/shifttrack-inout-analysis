# 実機スクショとの突き合わせ

48 枚は公開リポジトリに置いていない。個人の金額、勤務先の名前、住所、電話はここにも書かない。印 `観` はスクショで見えた配置であり、命令の `確` ではない。元の Swift ソースでもない。

## タブ

下の黒いカプセルに、左から 一覧、カレンダー、勤務先、年収、設定。選ばれている項目は緑の丸に白い記号、ラベルは白い小さい文字。

命令の `w21` は 0 が `slider.horizontal`、1 が `calendar`、2 が `building.2`、3 が `yensign`。スクショでは右端の設定が横スライダー、その左が円、その左が建物、その左がカレンダーに見える。左端の一覧の記号は、この 4 つの名前には入らない。`w21 == 0` を左端のタブだとは置かない。

各タブの上端には `in` / `OUT` のロゴと、丸い `questionmark` がある。

## 一覧（WorkplaceListView）

上から、ロゴ、`今週のシフト` と左右の山括弧、曜日の丸、日付、大きいドット書体の時刻、シフトのカードか「この日のシフトはありません」、黒い `+ シフトを追加`、その日のやること、黒い `今日のお給料` と白い `今月のお給料`、`今月の支給見込み`、`確認していない勤務`、タブ。

カードには日中の風景（カタログの `TimeDay` と同じ題材）、緑の丸に頭文字、`...`、`編集` に鉛筆、`MAP` / `電話` / `メッセージ`。時刻の幅はドット書体。やることを空のときは「この日のやることはありません。シフトの「編集」から追加できます。」

この並びはスクショの上から下であり、`VStack` の命令ではない。余白はカードの外側に一回りあり、角は大きく丸い。ポイント数は測っていない。

カードの中は、風景、頭文字の丸、`今日` と `編集`、時刻の幅、`MAP` / `電話` / `メッセージ`。`保存しました` の緑のピルは、ロゴの行と `今週のシフト` の間にある。カード上のメニューは `勤務先情報を編集`、`時給・割増設定`、`削除`。削除の確認は角丸のカードで、`キャンセル` と `削除` が横に並ぶ。金額と勤務先名は書かない。

## カレンダー（CalendarTabView）

月のグリッド、`シフト希望` と `選択`、色の丸の凡例、黒い `今月の収入見込み`、`シフトパターン` のチップと `+`、`毎週` と `+`。シフトのある日は黒い丸に緑の数字と、パターン色の点。今日は緑の丸。

複数選択のコマでは、上に `全て` と黒いチップ、ドットの月、`シフト希望` と `完了`、`日` から `土`、日付のカプセル。この月は横 7、縦 5 段。選んだ日は黒い枠とチェック。下に `今月の収入見込み` と、`日を選択中`、`外す`、パターンの行と `+`。金額と名前は書かない。間隔 6 と 8 の命令は `parallel-layout.md` で、この見た目とは別である。

`選択` のとき下から「日付を選んでください」とパターンのチップが出る。右上は `完了`。

日を開くと、上に日付と `xmark`、`シフトを追加`、パターンのチップ、時刻の横線、下に `勤務時間`。これは `CalendarDayView` のシートと見ておく。命令がそのシートだと証明したわけではない。

## シフト希望

`xmark`、題 `シフト希望`、右にドットの月、週のカードが横に 7 枚（選んだ日は黒い角丸）、シフトの行、下の白い角丸パネル。上段は `出勤` / `休み` / `時間指定`、下段は `クリア` と緑の `テキスト生成`。別のコマには「予定はありません」もある。名前と時刻は書かない。

`予定はありません` は `RequestHoursStockSheet` だけの関数が読み、`テキスト生成` は `ShiftRequestPlannerView` だけの関数が読む。スクショでは同じシートに両方ある。二つの型を一つの画面に合体させた、とは命令からは言えない。

## パターンと繰り返し

`シフトパターン` のシートは、`xmark`、`保存`、見出しの下の灰色の角丸欄、`勤務先` のチップ、`色` の 8 つの丸、`時間` の二つのカプセル、`やること` と `+`。シートの上角は丸い。`ShiftPartEditorView` と見ておく。チップの文字と時刻は書かない。

`曜日で置く` のシートは、パターンの選択、日〜土、`選んだ曜日に、このシフトパターンを置きます。`、`開始日を決める`、`終わりの日を決める`、`終わりの日を決めないと、ずっと続きます。`。後の二文はバイナリの cstring にある。題の `曜日で置く` は cstring としては見つかっていない。`ShiftRepeatEditorView` と見ておく。

## 勤務先（WorkplaceDirectoryView）

黒いカードに頭文字、時給のドット数字、ピンの住所、`MAP` / `電話` / `メッセージ`、下向きの山括弧で `シフトパターン` が開く。開いた中は、パターンの見出し、白い角丸の行、緑の `+`、上向きの山括弧。パターン行は右に山括弧。カードの外に緑の `+` と `勤務先を追加`。メニューは一覧と同じ三行。山括弧の上下は、命令がこの画面だけに渡す `chevron.up` / `chevron.down` と一致する。どちらが開く側かは、ビットの意味が未確定のまま。金額、名前、住所は書かない。

## 登録の 3 段（OnboardingView）

`01` `02` `03` と `xmark`。`勤務先を登録` は店の絵（`SetupWorkplace`）、`マップで探す`、`検索`、`店舗名`、`住所`、`連絡先`、`写真から読み取る`、`スキップ`、`追加して次へ`。`お給料の決まり` は財布の絵（`SetupPay`）、時給、適用開始日、締め日、`深夜割増（22時〜5時）`、割増率、残業、休憩、法定の 6 時間超 45 分と 8 時間超 60 分の文、`戻る`、`次へ`。`いつものシフト` は暦と時計の絵（`SetupCalendar`）、シフト名、開始、終了、毎週の曜日、`シフトの前に通知`、`はじめる`。これらの題は、オンボーディングだけを呼ぶ関数が読む cstring と一致する。

## 年収（IncomeView）と壁（WallEditorView）

年の大きいドット数字、緑の `保存しました` にチェック、黒い `年収の見込み`、`働いた分`、`年末までのシフト分`、`合計`、`数える日` の `働いた日` と `支給日`、`支給の見込み`、`年収の壁` と `+`。

壁のシートは `xmark`、`保存`、`金額`、`通知しない` / `割合で通知` / `残り金額で通知`。`残り金額で通知` は cstring にあり、読む関数は `LateMessageView` だけを呼ぶ。スクショでは壁のシートに出ている。同じ文言が二つの場所にある可能性は残し、命令の所属は動かさない。

## 設定（SettingsView）

`設定`、`メッセージの文章`、`通知` の `勤務の終わりに確認` と `シフトの前に通知`、`開始の前` の分ステッパー、`設定アプリで通知を許可`、`位置情報の許可` が `未設定`、`位置情報を許可する`、`シフトの重なり` の `勤務先の移動にかかる時間` の分ステッパー、`カレンダー・リマインダー` の `予定を表示`、`IN/OUT について` のバージョン、`プライバシーポリシー`、`お問い合わせ（メール）`、`about`。右向きの矢印は `arrow.up.right` と一致する見た目。広告の節は対象外。

移動時間のステッパーは、重なり検査の秒数の閾値と同じ画面にある。`x20` がそのステッパーの値だと命令は示していない。

## ガイド（GuideOverlay）

白いカード、`n/6` または `n/4`、`xmark`、本文、`戻る` と `次へ` または最後の `おわり`。緑の枠が対象を囲む。一覧は 6 枚、カレンダーは 6 枚、勤務先は 4 枚、年収と設定もある。本文のうちバイナリにあるものには、`今週の日付です`、`いま稼いだお給料`、`赤い`、`移動時間の不足`、`勤務先の移動にかかる時間` がある。ガイドは横スワイプと、黒い丸がシフトのある日であることを説明している。これは操作の `観` であり、ジェスチャ命令の `確` ではない。

## 起動、編集、許可、確認、支払い

起動は画面いっぱいの黄緑で、ロゴがあるコマと無いコマがある。そのあと一覧の左下に黄緑の円が重なる。`LaunchAnimationView` と見ておく。命令が `LaunchBackground` をこの画面で読むことは結んでいない。

勤務先の編集シートは、上から取り込み、`基本`、`サムネ`、`時給`、`連絡先`、`割増`、休憩の決まり、`住所・位置（任意）`、`この勤務先を削除`。カードは左右に余白がある。`サムネ` のアイコンは 6 列 2 行、色の丸は 8 つ。数値、名前、住所、電話は書かない。

位置のシートは、地図、説明、`現在地を使う` と `位置を外す`。カレンダーの許可は、ロゴ、見出し、説明、注意、下の黒い `設定アプリを開く`。遅刻の文章編集は、`宛名`、`丁寧`、`普通` の角丸欄と `最初の文章に戻す`。題の名前と欄の中の文は書かない。

`おつかれさまでした` は、`IN` と `OUT`、`休憩`、休憩帯、黒いカード、`内訳を見る`。奥に `確認していない勤務` の題がある。一覧の中身は写っていない。あやとの証言では、勤務の終わりにこのシートは自分では開かず、バイブだけである。

`支給の見込み` は、勤務先の行、赤い `!`、グループの角丸カード（`支払い`、期間）。吹き出しは支払日が未設定だと書く。`支払い` の画面は、周期のカード、締め日と支払日のカード、`土日の支払日`。メニューは `そのまま`、`前の金曜日`、`次の月曜日`。金額と名前と、行の右の選択値は書かない。

給料期間の詳細は、丸い戻ると期間の題、白いグループカード（`支給期間`、見出し `内訳`、見出し `勤務`）、灰色のカプセル（`総支給額`、`差引支給額`）、`メモ`、`明細の金額を保存`。カードの間と左右に余白がある。金額、日付、時刻は書かない。詳細は `parallel-layout.md`。

## スクショに無い画面

取り込み結果、概要の中身、遅刻メッセージの作成、遅刻定型の一覧、内訳、未確認勤務の一覧の中身、シフト編集の保存シート（`このまま保存`）、Todo の編集シート。サムネイル型だけの画面は無く、編集シートの `サムネ` は上のとおり。期間の詳細に `内訳` の見出しは見える。`PayBreakdownView` だけの画面は、まだここに無い。
