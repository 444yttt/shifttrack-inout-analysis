# 余白・角丸と積み順

元の Swift ソースではない。広告と Intelligence は対象外。画像、フォント、`Assets.car` はこのリポジトリに置いていない。個人の金額、勤務先名、住所、電話は書かない。

`確` は、その画面のアクセサだけを呼ぶ関数、または既に結んである body の中にある即値。`部` は、複数の画面を呼ぶ関数の中にある即値。`観` はスクショの見た目で、命令の証明ではない。スクショの上下を `確` にはしていない。

## 命令。カレンダーの間隔

`CalendarTabView` のアクセサ `0x100071b0c` だけを呼ぶ関数に、間隔の即値がある。

`0x100058000` は `0x100058030` でこのアクセサを呼ぶ。呼び出し元 `0x100057dac` の関数 `0x100057bc4` も、このアクセサだけを呼ぶ。

`0x1000583e8` は `tbz w20, #0` で `0x1000584b0` へ飛ぶ。ビット 0 が 0 の側が `LazyVGrid`、1 の側が `LazyVStack` である。このビットが画面のどの状態かは、命令では閉じていない。二つのコンテナを上下に積む順ではない。

| 側 | 呼び出し | 間隔 |
| --- | --- | --- |
| ビット 0 が 1 | `0x100058488` の `LazyVStack` | `x1` が 8.0 のビット `0x4020000000000000`、`w2` が 0 |
| ビット 0 が 0 | `0x10005856c` の `LazyVGrid` | `x2` が 6.0 のビット `0x4018000000000000`、`w3` が 0 |

`VStack` の Optional と同じ読みで、タグ 0 は値がある。スタブは `LazyVStack` が `0x1003fd238`、`LazyVGrid` が `0x1003fe738`。

同じ画面だけの `0x100070788` は、`0x100070efc` でアクセサを呼ぶ。`0x10007196c` は `GridItem` の spacing に 6.0、タグ `w2` は 0。`w5` は 1 で、同じ Optional の読みでは alignment は空。スタブは `0x1003fe654`。直後の `0x100071988` は `w0 = 7` で `_allocateBufferUninitialized(minimumCapacity:)`（`0x1003feb64`）を呼ぶ。7 は確保容量であり、列数としては確にしていない。この関数を呼ぶ `0x100180b74` は他の画面も呼ぶ。即値があるのはカレンダーだけの関数の中なので、余白は確。

スクショの月グリッドが横 7・縦 5 に見えることと、上の 6 と 8 と容量 7 は、別の根拠である。見た目で間隔の数字は確にしていない。子ビューの構築順は取れていないので、積み順は観のまま。

## 命令。画面へ結べなかった即値

次の関数の入口は、`bl` も `adrp` + `add` も、相対 32 ビットのポインタも無い。呼び出し元が画面へ結び付かないので、未のまま。

| 関数 | 中にあるもの |
| --- | --- |
| `0x100026364` | `VStack` 間隔 8 |
| `0x100029f00` | `VStack` 間隔 24、`padding` 20 |
| `0x10002c99c` | `VStack` 間隔 0、余白 20 と 16 |
| `0x10002d03c` | `VStack` 間隔 0 |
| `0x1000237bc` | `HStack`、余白 16 |
| `0x10002d818` | `HStack` |
| `0x100089b00` | `HStack` |
| `0x100055c88` | `VStack` 間隔 0、余白 24 |
| `0x100055ddc` | 余白 20 と 12 |
| `0x1001a5a5c` | `presentationCornerRadius` 32 |
| `0x10020ad88` | `presentationCornerRadius` 32 |
| `0x10027b7c0` | `GridItem` 間隔 8。呼び出し元 `0x10027b3b4` も画面アクセサを呼ばない |

`WorkplaceThumbnailView` のアクセサ `0x10027a1d8` を呼ぶ関数は無い。アイコンが 6 列 2 行に見えることは、編集シートの観であり、この型の確ではない。

`VStack` の直接呼び出しはバイナリ全体で 5 のまま。`ZStack` の `0x100256064` は `0x100255ab0` にあり、一覧と一緒に勤務先エディタ、支給期間、未確認、オンボーディング、遅刻、シフト編集を呼ぶ。子の順は取れていない。一覧だけの `0x100256d78` は `TupleView` を 1 回作る。子ビューの名前は命令に残っていない。積み順の確は 0 のまま。

角丸 32 のうち、日ビューの body `0x10003cdd8` の `0x10003d5ac` は、これまでどおり日ビューの確。同じ関数は `ShiftEntryEditor` も呼ぶので、編集側は部。`0x100104588` の 32 はオンボーディングと取り込みの部。

## スクショの観

ポイント数は測っていない。金額、勤務先名、住所、電話、パターン名は書かない。

### 起動（LaunchAnimationView）

余白は観。画面いっぱいに黄緑があり、ロゴがあるコマでは中央にロゴがある。次のコマは同じ黄緑でロゴが無い。その次は一覧が出ていて、左下に黄緑の大きな円がタブへ重なる。カタログの `LaunchBackground`（195, 255, 119）と同じ色味に見える。命令がこの画面でその名前を読むことは結んでいない。

積み順のセルは未。上から下へ部品が並ぶ画面ではなく、コマの移りである。

### 起動のあと（WorkplaceListView）

積み順と余白は、これまでどおり観。上から、ロゴと丸い `?`、`今週のシフト` と左右の山括弧、曜日の丸、日付、ドットの時刻、カードか空の文言、`+ シフトを追加`、`今日のやること`、`今日のお給料` と `今月のお給料`、`今月の支給見込み`、`確認していない勤務`、タブ。

カードの中は、上から風景、頭文字の丸と `...`、`今日` と `編集`、時刻の幅、`MAP` / `電話` / `メッセージ`。カードの角は大きく丸い。外側に余白がある。

`保存しました` の緑のピルは、ロゴの行と `今週のシフト` の間にあり、幅は画面いっぱいではない。

カード上のメニューは、上から `勤務先情報を編集`、`時給・割増設定`、`削除`。白い角丸。削除の確認は角丸のカードで、下に `キャンセル` と `削除` が横に並ぶ。題に勤務先名が入るので、題は書かない。

### 勤務先のカード（WorkplaceDirectoryView）

積み順と余白は観のまま。開いた黒いカードの中は、上から頭文字の丸、時給のドット、ピンの行、`MAP` / `電話` / `メッセージ`、`シフトパターン`、白い角丸のパターン行、緑の `+`、上向きの山括弧。カードの外に `勤務先を追加`。閉じたメニューは一覧と同じ三行。角は大きく丸く、カードの外に余白がある。

### 勤務先の編集（WorkplaceEditorView）

余白と積み順を観にした。シートの上角は丸い。カードは左右に余白があり、カードの間が空く。見出しはカードの外、左。

上から、丸い `x` と `勤務先を編集` と丸い `保存`、`読み取って入力（任意）`、取り込みのカード（`ショップカードを撮影`、`写真からショップカードを選ぶ`、`Google マップのリンクを貼り付け`）、`基本`（`名前`、`支払い`）、`サムネ`、`時給`、`連絡先`、`割増`、`勤務先の決まりで休憩を設定` のカード、`住所・位置（任意）`、`この勤務先を削除`。`休憩` という見出しは、この連なりには写っていない。各行の数値は書かない。

`サムネ` は、丸い印、`頭文字` / `アイコン` / `写真`。頭文字のときは色の丸が 1 列。アイコンのときは円が 6 列 2 行で、その下に色の丸。色は 8 つで、左端に輪がある。

### シフトパターン（ShiftPartEditorView）

余白と積み順は観のまま。シートの上角は丸い。`x` と `保存` は円。見出しの下に灰色の角丸欄が一部見える。ラベルは、このコマでは欄の上に出ていない。その下は `勤務先` の丸いチップ、`色` の 8 つの丸（左端に輪）、`時間` のカプセルが二つ、`やること` の灰色の角丸欄と右の `+`。左右に余白がある。キーボードはシステムのもので、このシートの積み順には数えない。

このコマで読めたラベルは `シフトパターン`、`保存`、`勤務先`、`色`、`時間`、`やること`。チップの文字と時刻の数字は書かない。文言のセルは動かしていない。

### 位置（LocationPickerView）

余白と積み順を観にした。上から、戻る、`位置`、地図、`地図をタップして勤務先の位置を選びます。`、下に `現在地を使う` と `位置を外す`。ボタンは角丸で、間が空き、左右に余白がある。地図上の店名は書かない。

### カレンダーの許可（CalendarAccessView）

余白と積み順を観にした。上にロゴ、間が空いて `シフトはカレンダーアプリに保存します`、説明、許可が無いときの注意、下に黒い大きな角丸の `設定アプリを開く`。ボタンは左右に余白がある。

### カレンダーの複数選択（CalendarTabView）

積み順は観のまま。余白のセルは、上の間隔の命令で確にした。この節の並びは、その確の根拠ではない。

上から、`全て` と隣の黒いチップ、ドットの月と `シフト希望` と `完了`、`日` から `土`、日付のカプセル。この月は横 7、縦 5 段。今日に見える日は緑の塗り、別の日は黒塗りに緑の点、選んだ日は黒い枠とチェック。下に凡例、黒い `今月の収入見込み`、`日を選択中` と `外す`、パターンの行と `+`。金額と名前は書かない。

### シフト希望（ShiftRequestPlannerView）

余白と積み順を観にした。上から、`x` と `シフト希望` と右のドットの月、週のカードが横に 7 枚（左右に山括弧。選んだ日は黒い角丸、ほかは白い角丸。曜日、日、点）、日付の行、シフトの行、下の白い角丸パネル。パネルの上段は `出勤`、`休み`、`時間指定`。下段は `クリア` と緑の `テキスト生成`。カードの間と、パネルの左右に余白がある。題の下の名前と、行の時刻は書かない。

`予定はありません` を読む関数と、`テキスト生成` を読む関数は別の型のまま。このシートの見た目で二つの型は合体させていない。

### おつかれさま（ShiftCheckView）

積み順は観のまま。余白を観にした。奥に `確認していない勤務` の題と `x`。手前のシートは、上から `おつかれさまでした` と `x`、横並びの `IN` と `OUT`、`休憩` のステッパー、`休憩の時間帯を入れる`、黒い角丸（`働いた時間`）、`内訳を見る`。`IN` と `OUT` の間が空き、黒いカードの角は大きい。時刻と金額と名前は書かない。

あやとの証言では、勤務が終わったときにこのシートは自分では開かず、バイブだけである。証言であり、命令の確ではない。このスクショは `確認していない勤務` の上に開いた状態である。

### 遅刻の文章（LateTemplateEditorView）

余白と積み順を観にした。丸い `x`、中央の題、丸い `保存`。題は勤務先名なので書かない。その下は `宛名`、`丁寧`、`普通` のラベルと、それぞれの灰色の角丸欄。下に `最初の文章に戻す` と緑の `?`。欄の中の文面は書かない。

### 支給の見込み（PayPeriodsView）

積み順は観のまま。余白を観にした。シートの上角は丸い。上から、`x` と `支給の見込み`、勤務先の行と赤い `!`、白い角丸のグループカード。カードの中は区切りで、`支払い` と `未設定`、その下に期間と `支給日 未設定`。`!` の吹き出しは `支払日が未設定です。「支払い」で設定すると、支給日が出ます。` カードは左右に余白がある。金額と名前は書かない。

### 支払い（PayScheduleEditorView）

余白と積み順を観にした。題が `支払い` で、`土日の支払日` が見える。その文言は、この画面だけの関数が読む。セクションの上下はスクショの観であり、`VStack` の確ではない。

戻る、`支払い`。見出し `支払い` の白い角丸カードに `支払日を設定する` とスイッチ、`支払いの周期`。注記は `支払いの周期は給与の方式（時給・日給）とは別です。` 見出し `締め日と支払日` のカードに `締め日`、`支払う月`、`支払日`。注記は `締め日の翌日から次の締め日までが1回分です。31日のない月は月末に支払う計算にします。` その下のカードが `土日の支払日`。注記は `祝日は判定していません。` 見出しはカードの外にあり、カードの間と左右に余白がある。

`土日の支払日` のメニューは、上から `そのまま`、`前の金曜日`、`次の月曜日`。白い角丸。行の右に出ている選択中の値は書かない。

### 給料期間の詳細（PayPeriodDetailView）

余白を観にした。積み順は観のまま。シートの上角は丸い。左に丸い戻る、中央に期間の題。白い角丸のグループカードが縦に並び、カードの間と左右に余白がある。見出しはカードの外、左。

見えている白いカードは、上から、`支給期間`、`支給日`（右に山括弧）、`支給の見込み`。見出し `内訳` のカードは `時給`、`働いた時間`、`支給の見込み` で、カードの中の注記は `税金・社会保険は計算していません。` 見出し `勤務` のカードは `確認済み`、`未確認`、`これからのシフト`、その下にシフトの行と `予定`。カードの下に `終わった勤務を押すと、時間・休憩を確認できます。` と `給与明細と照らし合わせる`。その下は灰色のカプセルが `総支給額` と `差引支給額`、`メモ`、`明細の金額を保存`、長い注記。金額、日付、時刻は書かない。

`Section.create` は `0x10014bcdc` に 4 回ある。この関数は上の注記と `給与明細と照らし合わせる` と、明細と見込みの差の説明を読む。画面アクセサは呼ばない。尾呼び出し `0x100157c9c` のアドレスを取る `0x10014a990` は、明細と `ShiftCheckView` を両方呼ぶ。`Section` の呼び出しは、アクセサだけの関数の中には無い。4 つの節も、角丸の数値も、確にしていない。
